# Advanced-Predictions-and-Identification-of-Material-Behavior-from-Curve-Shape-Indices.-

This project presents a machine learning–based approach to estimate constitutive model
parameters by leveraging shape-related indices extracted from stress–strain curves.
Regression models are applied to predict the parameters of both the Swift and
Johnson–Cook models, and the predicted responses are compared against experimental
and simulated data. The proposed methodology reduces the reliance on time-consuming
experimental procedures, improves parameter estimation accuracy, and enhances the
predictive capability of material models, offering a robust and scalable tool for both
research and industrial applications.
